# AeroSpeed GPS - High-Precision Speedometer & Telematics Knowledge Center

A modern, high-precision online GPS speedometer web application and telematics knowledge hub. Built with Vanilla JavaScript, HTML5, CSS3, and PWA capabilities.

## 🚀 Features
- **Real-Time Satellite GPS Speedometer**: Uses Geolocation API and Doppler calculations for high-accuracy speed tracking.
- **Night HUD Windshield Mode**: Mirrors the screen horizontally for heads-up display projection on car windshields.
- **Multi-Unit Telemetry**: Instant switching between KM/H, MPH, Knots, and M/S.
- **0-60 MPH / 0-100 KM/H Performance Timer**: Automatic drag-strip timer with millisecond precision.
- **Interactive Speed Simulator**: Test all gauges, dials, and alerts directly from your desktop.
- **Progressive Web App (PWA)**: Installable on iOS & Android with offline caching via Service Worker.
- **Telematics Knowledge Base**: 20+ comprehensive technical guides on vehicle metrology, OBD2 sensors, and speed physics.

## 🛠️ Tech Stack
- Vanilla HTML5 / CSS3 (Dark & Light Theme Support)
- Pure JavaScript (No heavy frameworks, Core Web Vitals 100/100)
- HTML5 Canvas for real-time analog gauge rendering
- Web Audio API for speed chime alarms

## 📦 Getting Started Locally
```bash
# Clone the repository
git clone https://github.com/mokshith1222/speed_check.git

# Navigate into directory
cd speed_check

# Run dev server
npm run dev
```
